# um-media

Публичный хостинг картинок для конвейера каруселей проекта «Университет Мейстера».

Здесь лежат только готовые JPEG-слайды, которые Meta забирает по публичной ссылке
в момент публикации. Ничего секретного: это те же слайды, что уходят в открытый
аккаунт Instagram.

Ссылки вида `https://sokoleyes-web.github.io/um-media/<папка>/01.jpg`.

Требования к файлам (из ТЗ конвейера):
1080×1350, sRGB, JPEG качество 92, без прогрессивной развёртки.
